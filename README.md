# Aurora Paralela

Screensaver de una aurora cosmica implementado en C++ y OpenMP para el Proyecto 1
de Computacion Paralela y Distribuida.

El programa tendra una version secuencial y dos versiones paralelas comparables.
`N` representa la cantidad de fuentes luminosas que forman el campo animado.

## Estado

Estructura inicial del proyecto. Las instrucciones de compilacion, uso y medicion se
completaran junto con la implementacion.
